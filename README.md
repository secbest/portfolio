# Portfolio

Personal portfolio of Jasper Teo Kheng Cher, built for K0126002 Web Programming at Gachon University.

Live site: https://secbest.github.io/portfolio/

## What is in it

- Semantic HTML: skip link, `header`, `nav`, `main`, `footer`
- Responsive CSS (Flexbox and Grid), checked at phone width
- JavaScript: dark mode toggle (remembers your choice) and a project filter
- Accessibility: Lighthouse score 100, alt text on the image, WCAG AA colour contrast in both themes

## Files

- `index.html`: the page
- `css/style.css`: styles and light/dark colour tokens
- `js/main.js`: theme toggle and project filter
- `images/profile.jpg`: placeholder photo (replace with your own, same filename)
